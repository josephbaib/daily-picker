# Правила для агента в этом репозитории

Полная спека проекта: `docs/SPEC.md`. Читать перед любой правкой. Ниже то, что нарушать нельзя.

- Итог игры считается до анимации из сида. Всё случайное только из сида. Симуляции фиксированным шагом от времени.
- События в играх фиксировать по прошедшему времени, не по кадру. Никаких ожиданий `requestAnimationFrame` в логике переходов.
- Фоновые элементы привязывать к мировой координате, не к порядку цикла.
- Персонажи только из набора LPC (`assets/lpc`) или заказных листов. Чужую графику из игр не скачивать. Новые части записывать в `assets/CREDITS.md`.
- Тестировать только в комнате `ba-test`. Каждую затронутую игру прогонять в браузере до результата.
- Перед пушем: `npm test`, затем `python3 tools/bump-version.py`.
- Пиксельный стиль только внутри игрового окна. Интерфейс в стиле меню PS2, без CSS-теней и фильтров в анимации.
- Локальный сервер запускать из Bash с заголовком no-store (`scratchpad/serve.py`), а не через превью.
- Проработка: ни одного одноцветного прямоугольника как готового объекта, три тона на объект, три плана с параллаксом, в любом квадрате 200×200 есть деталь, не меньше пяти живых элементов фона, свечение у источников света. Полный список в разделе 4 спеки. Эталон картинки и схема производства фона в `docs/BENCHMARK.md`: фон новой игры собирается из нарисованных плит (`assets/scenes/<игра>/`), обработанных `tools/pixelize.py`, в буфере 640×360 с целочисленным масштабом; процедурный фон из прямоугольников для новой игры не принимается. Образец сборки — `js/games/rooftops.js`; общие функции (`makeBuffer`, `plate`, `drawTiled`, `glow`, `lightPool`, `placeLabels`, `fogBank`) в `js/games/scene.js`; плиты игры перечисляются в поле `assets`, приложение грузит их заранее.
- Всё, что рисуется поверх плит (персонажи, имена, надписи, эффекты, показания), подчиняется свету, палитре, сетке и физике сцены. Правила в `docs/STAGE.md`. Разбор всего продукта (игры, персонажи, текст, эффекты, вход и выход из игры, меню, звук) и общий порядок работ в `docs/ROADMAP.md`.
- Планка качества игры и определение «сделано» в разделах 4 и 8 спеки.
