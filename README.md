# Daily Picker

Игра, которая за 10–40 секунд выбирает, кто говорит первым на дейлике, и порядок остальных.

- Страница: https://josephbaib.github.io/daily-picker/?room=<имя-комнаты>
- Список участников общий, редактируется на странице, память «кто был первым вчера» хранится в Supabase.
- Игры: гонка и «последний выживший». Кто нажал «Старт», у того и у всех, кто открыл ссылку, игра идёт синхронно с одинаковым исходом.

## Запуск локально

```bash
python3 -m http.server 8765
```

Открыть `http://127.0.0.1:8765/?room=test`.

## Выкладка

Перед пушем: `python3 tools/bump-version.py` — ставит новую версию во все импорты и картинки, чтобы браузеры не держали старый кэш.

## Тесты

```bash
npm test
```

## База

Миграции в `supabase/migrations/`. Если GitHub-интеграция не применила их, вставить SQL вручную в Supabase → SQL Editor.

Общая спека проекта: `docs/SPEC.md`. Промпты для персонажей: `docs/prompts.md`. Спеки и планы по этапам: `docs/superpowers/`.
