# Daily Picker — план реализации первой версии

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Веб-игра, которая за 10–40 секунд выбирает порядок выступлений на дейлике, с общим списком участников и памятью между днями.

**Architecture:** Статическая страница на GitHub Pages, ванильный JS модулями без сборки. Supabase хранит комнаты и историю игр и рассылает событие старта, чтобы у всех открывших ссылку игра шла синхронно и с одинаковым исходом. Итог считается до анимации из сида и правил честности, игры только разыгрывают его.

**Tech Stack:** HTML, CSS, JS-модули, Canvas 2D, Web Audio, supabase-js через CDN, `node --test` для чистой логики, Supabase Postgres + Realtime, GitHub Pages.

Спека: `docs/superpowers/specs/2026-09-08-daily-picker-design.md`.

## Файлы

|---|---|
| `index.html`, `css/app.css` | Разметка одного экрана и стили в пиксельной стилистике |
| `js/config.js` | URL и publishable key Supabase |
| `js/rng.js` | Mulberry32 по сиду, FNV-1a хэш строки, случайный сид |
| `js/order.js` | Веса на первое место и расчёт полного порядка |
| `js/avatar.js` | Герой из имени: причёска и цвета, спрайт 12×16, отрисовка |
| `js/db.js` | Supabase: комната, история, подписки, канал старта, поправка часов |
| `js/sound.js` | Чиптюн через Web Audio, по умолчанию выключен |
| `js/themes/pixel16.js`, `js/themes/index.js` | Тема А: небо, параллакс, земля, факелы, финиш, табличка, карточка |
| `js/games/race.js`, `js/games/survivor.js`, `js/games/index.js` | Две игры и реестр с режимом «случайная» |
| `js/ui/participants.js`, `js/ui/result.js` | Панель участников и финальный экран с конфетти |
| `js/app.js` | Состояние экрана, старт, отсчёт, обработка событий |
| `supabase/migrations/20260908170000_init.sql` | Таблицы `rooms`, `games`, RLS, реалтайм |
| `tests/*.test.js` | Тесты на rng, order, avatar |

Контракты, которые связывают модули:

```js
// participant в приложении
{ id: 'a1b2c3', name: 'Юсуф', present: true, avatar: { hair, hairColor, skin, shirt, pants } }

// game
{ id, title, duration, minPlayers, maxPlayers,
  play({ canvas, theme, participants, order, seed, onFreeze, onEvent }) -> { stop() } }

// событие старта в broadcast-канале room:<id>
{ gameId, game: 'race' | 'survivor', seed, orderIds: [...], startAt: <серверное время, мс> }
```
