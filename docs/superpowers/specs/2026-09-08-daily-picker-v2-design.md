# Daily Picker v2 — работа над ошибками

Дата: 2026-09-08. Статус: согласовано в чате, в работе.

## Что не так в v1 (обратная связь после первого показа)

1. Нет нормального меню, всё на одном экране.
2. Пиксельный стиль размазан на весь интерфейс, а не только на игру.
3. Персонажи слишком простые, 12×16 без теней.
4. Персонажи не похожи на реальных людей.
5. Гонка рисовалась с артефактами (исправлено сразу: дорожки не перерисовывались), «последний выживший» выглядит бедно. Игры должны развлекать.

## Решения

| Вопрос | Решение |
|---|---|
| Меню | Отдельный экран-хаб в стиле домашнего экрана приставки: крупные плитки игр с подсветкой выбранной, состав команды портретами с переключателем «сегодня тут», большая кнопка «Играть». Стрелки и Enter работают |
| Стиль интерфейса | Обычный современный тёмный интерфейс, шрифт с Google Fonts (Rubik). Пиксельная графика только внутри игрового окна и на портретах |
| Персонажи | Спрайт 24×32 с контуром, тенью и бликом, четырёхкадровый бег, кадры «радуется» и «падает». Собирается из частей: причёска, борода, очки, головной убор, тип и цвет одежды, цвет кожи, штаны, обувь |
| Реальные люди | Юсуф присылает фото и имя, параметры персонажа подбираются вручную и зашиваются в `js/roster.js` по имени. Фото не хранятся. Кого добавили на странице, тот собирается случайно из тех же частей по хэшу имени |
| Гонка v2 | Одна широкая трасса стадиона: бегуны в несколько рядов в глубину, трибуна с толпой, пыль, смена лидера, замедление и вспышка на финише |
| Выживший v2 | Арена: персонажи стоят на площадке под прожекторами, каждый раунд одного уносит событие (люк, молния, луч с неба), прожектор мечется перед выбором жертвы, последний на пьедестале |
| Результат | Тот же экран в стиле хаба: портрет и имя первого, порядок, «Ещё раз» и «В меню» |

Механика синхронизации, база, честность и контракт игры из v1 не меняются.

## Инструмент для персонажей

Спрайты рисуются текстовыми сетками в `tools/sprites.py`, там же предпросмотр в PNG. Скрипт генерирует `js/sprite-data.js`, руками этот файл не правится.

## Состояние на 2026-09-08 вечер

Собрано и выложено: хаб в стиле консоли, спрайты 24×32 из частей (`tools/sprites.py` → `js/sprite-data.js`), забег на стадионе, арена, экран результата. Проверено локально на комнате `ba-test`: обе игры проходят до результата, ошибок в консоли нет, сторожевой таймер показывает итог, даже если игра зависнет.

Открыто: портреты реальных людей (`js/roster.js` пуст, ждём фото), полировка рук в кадрах бега, второй тестовый прогон на живом дейлике.
